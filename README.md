# 🌀 Surface Plasmon Polaritons in Multilayer Structures

## 📌 Описание проекта

Этот проект посвящён численному исследованию **поверхностных плазмон-поляритонов (SPP)** в многослойных структурах, включая металл-диэлектрик, а также более сложные конфигурации с анизотропными и периодическими слоями (фотонные кристаллы). 

Методика основана на **решении уравнений Максвелла** в TM-поляризации и **поиске собственных мод** в структурах с различной геометрией.

Проект использует **метод матриц переноса (Transfer Matrix Method)** и включает:
- вычисление мод в многослойных структурах,
- анализ распределения электромагнитных полей,
- визуализацию вектора Пойнтинга и локализации энергии,
- поддержку анизотропных сред.

---

## 📈 Основные уравнения

**Поле для TM-поляризации** представляется в виде:

$$
\mathbf{E}(x,z,t) = \mathbf{E}(z) e^{i(k_x x - \omega t)}, \quad 
\mathbf{H}(x,z,t) = \mathbf{H}(z) e^{i(k_x x - \omega t)}
$$

Компоненты полей выражаются через \( H_y \):

$$
E_x = -\frac{i}{\omega \varepsilon_0 \varepsilon_x} \frac{\partial H_y}{\partial z}, \quad
E_z = \frac{i k_x}{\omega \varepsilon_0 \varepsilon_z} H_y
$$

Решение для продольного волнового числа в каждом слое:

$$
k_{zm} = \pm \sqrt{\frac{\omega^2 \mu_y \varepsilon_x}{c^2} - \frac{\varepsilon_x}{\varepsilon_z}k_x^2}
$$

---

## 🔁 Метод матриц переноса (Transfer Matrix Method)

Метод применяется для анализа мод в многослойной структуре. Каждому слою соответствует матрица передачи, и вся структура описывается произведением таких матриц:

$$
\begin{pmatrix}
E(z+L) \\ 
H(z+L)
\end{pmatrix}
= M \cdot 
\begin{pmatrix}
E(z) \\ 
H(z)
\end{pmatrix}, \quad
M = M_1 M_2 \dots M_N
$$

Условие существования моды:

$$
\det M(k_x) = 0
$$

Поиск моды сводится к **поиску комплексного значения \(k_x\)**, при котором определитель системы обращается в ноль.

## ⚙️ Запуск проекта

1. Установи зависимости (если используются):
   ```bash
   pip install -r requirements.txt
    ```

2. Построение зависимостей полей от глубины проникновения:

   ```bash
   python main.py
   ```

## 📌 Возможности

* Поддержка **анизотропных сред** (тензорная ε)
* **Периодические структуры** (1D фотонные кристаллы)
* **Автоматический поиск комплексного $k_x$** и построение дисперсионных диаграмм
* Расчёт **вектора Пойнтинга** и **локализации энергии**
* Исследование аналогов **резонансных мод интерферометра Фабри-Перо**
